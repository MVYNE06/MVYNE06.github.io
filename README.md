# Aaron Vaz — Interactive 3D Developer Portfolio

A high-performance, cyberpunk-inspired terminal HUD and personal portfolio. The experience pairs an interactive 3D WebGL avatar created in Spline with a responsive, glassmorphic command-line interface.

**Live Demo:** [https://mvyne06.github.io](https://mvyne06.github.io)

---

## 🚀 Key Features

- **Real-Time Cursor Tracking:** Embedded Spline 3D avatar configured with global event binding to dynamically track cursor position across the entire viewport.
- **Cyber-Command HUD:** CLI boot prompt with executable terminal scripts for exploring technical stacks, projects, achievements, and background.
- **Glassmorphism UI:** Ultra-translucent HUD modal architecture using CSS backdrop filters to maintain 3D scene visibility and maximize interactive viewport space.
- **Hardware-Accelerated CRT Shader:** Lightweight scanline effects overlay and live telemetry coordinates calculating simulated quaternion angles.

---

## 🛠️ Tech Stack

- **3D & Creative:** Spline 3D, WebGL
- **Front-End:** HTML5, Modern CSS3, JavaScript (ES6+)
- **Design System:** Glassmorphism, Monospace Typography, CRT Scanlines
- **Tools & Workflows:** Termux, ADB, Google Gemini, GitHub Pages
